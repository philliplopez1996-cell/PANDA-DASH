# Panda Dash

A portrait runner starring the PandaPals panda: jump the rocks, duck the hanging bamboo, fly through the gates and collect coins.

- `index.html` is the whole game, with all art embedded. Open it in any browser.
- Hosted with GitHub Pages from the `main` branch, root folder.
- Scores, coins, skins and stage progress are saved in each player's browser.

Controls: tap, Space or Up to jump (tap again in the air for a double jump), hold to fly, P to pause, M for music, H for home.
